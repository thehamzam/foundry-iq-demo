# Support

This repository is a personal public sample and is provided without a support
SLA.

## Public issues are appropriate for

- reproducible bugs in the synthetic, offline, or quickstart behavior;
- broken public documentation links;
- focused feature requests;
- questions about the documented sample architecture.

Use the repository issue templates and remove secrets and environment-specific
identifiers before posting.

## Public issues are not appropriate for

- suspected security vulnerabilities; follow [Security](./SECURITY.md);
- production incidents or architecture approval;
- Azure billing, quota, outage, or account support;
- legal, compliance, fraud, dispute, or institutional-policy advice;
- troubleshooting that requires customer data, tenant captures, credentials, or
  private resource details.

For Azure platform incidents or account-specific problems, use the applicable
official Azure support channel. Maintainers may close requests that cannot be
reproduced with synthetic data or that fall outside this sample.
