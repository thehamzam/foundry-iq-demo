## 4. General Filing Deadline for LAB-NET-12.6.2

For Lane A, the general filing deadline for **LAB-NET-12.6.2 is 44 synthetic calendar days** after the fictional event marker. This number is invented. It does not correspond to a real network deadline. Day zero is the event marker; counting starts on the next synthetic interval.

The next headings define Lane B and Lane C. Their different numbers are scoped rules, not amendments to Lane A. Chunking tests should verify that retrieval carries the lane with the deadline.

## 5. Lane A Acknowledgement

Lane A requires acknowledgement within **2 synthetic business days** after intake. The acknowledgement only confirms that a lab record exists. It does not validate the event or start a real process. The phrase synthetic applicability scope must accompany the answer.

## 6. Evidence Retention Baseline

Retain the synthetic evidence packet for **19 synthetic months** after drill closure. This baseline applies to Lanes A and C. The packet contains only invented labels and citations. Section 10 provides a shorter sandbox rule for Lane B.

## 7. Lane B Sandbox Entry Condition

A record enters Lane B only when it carries both **SANDBOX-REPLAY** and **NO-EXTERNAL-ACTION**. A label that merely contains “sandbox” is insufficient. Lane B exists to test scoped exceptions and must never trigger upload, filing, messaging, or cloud mutation.

## 8. Boundary Exception - Lane B Filing Window

For a valid Lane B sandbox replay, the LAB-NET-12.6.2 filing window is **61 synthetic calendar days**, not 44. The 61-day exception applies only when both Section 7 markers are present. It does not alter Lane A. Sections 7 and 8 are intentionally separated so a small chunk may capture the condition without the number or the number without the condition.

## 9. Lane B Acknowledgement Rule

Lane B acknowledgement is due within **5 synthetic business days**, not 2. This looks inconsistent with Section 5 only when synthetic applicability scope is omitted. Section 5 controls Lane A; Section 9 controls Lane B.

## 10. Lane B Retention Exception

Lane B evidence is retained for **7 synthetic months** after drill closure. The Section 6 baseline remains 19 synthetic months for Lanes A and C. A response saying “retention is seven months” without Lane B scope is incomplete.

## 11. Lane C Archive Verification

Lane C uses no filing deadline because it verifies an already closed fictional archive record. It retains the 19-synthetic-month baseline and uses a **4 synthetic business day** acknowledgement. The absence of a filing deadline is not an unlimited deadline.

## 16. Deadline Collision Examples

## 17. Exception Precedence
